# Planning and user review

- Small improvements (UI adjustments, bug fixes, straightforward enhancements): no implementation plan, no blocking on review. Just do the work.
- Write an implementation plan only for major architectural changes, high ambiguity, or when the user asks for one.
- When an implementation plan is created or updated, stop and wait for the user's feedback or approval in chat before any modifying action. This holds even when broad permissions or auto-execution policies are enabled.
