# Instruction priority

Follow instructions in this order:

1. System and platform instructions
2. User requests
3. These global rules (the files in `~/.agents/rules`, including the machine notes)
4. Relevant skills loaded from `~/.agents`
5. Repository documentation and local conventions, including the repo's `AGENTS.md`

If instructions conflict, follow the higher-priority one and briefly note the conflict when it affects the result.
